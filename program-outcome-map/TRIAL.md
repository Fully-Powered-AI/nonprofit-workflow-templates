# Program outcome map: one trial on its invented example

- **Product:** Claude, run in Claude Code

Model: Claude Sonnet 5.5 (model ID claude-sonnet-5-5), run as a coding-agent session with file access, not in a chat window.
Date: 2026-11-10.

The inputs were the invented example in [example.md](example.md), the Kestrel Lane Reading Project, as it stood at the run (the A4 Notes then read "Each child takes books home to keep"; the example has been edited since, as the section on changes after the run lists). No client data was used. The run followed the instruction block in the complete template and its output format. Only the example's inputs were read before the map was produced; the example's own map and the reviewer checklist were read afterwards, for comparison.

## Inputs used

The five input files and the settings in the section "The inputs" of [example.md](example.md): 4 activities, 4 outcomes, 5 measures, 1 baseline row, 4 feedback items, and the settings (program, evaluation, leads, data period, two other influences).

## What was observed

- Every required part was produced, in the order the format gives. The check lines added up. The run did not stop for anything: no header mismatch, repeated ID, personal information or request that the template says to decline came up. The unapproved comment (F3) was counted and not described.
- The result matches the published example closely: the same four links (three stated, one proposed, A4 to O3), the same evidence status on each link, the same three counts set aside, the same five decisions and the same 13 questions in the same places. The figures agree with the inputs.
- Differences from the published example:
  - Assumptions. For Link 1 the example's second assumption is about the measure (words per minute stands for fluent reading). The template's step 7 asks for what has to be true for the activity to lead to the outcome, and the run followed that. The other "assistant's reading" assumptions are worded differently from the example's.
  - Proposed measures. The example puts P3 (which names A4) on Link 4 only and P2 on Links 3 and 4. The run put P2 and P3 on both links of O3. P1 to P3 are worded differently, and the example's P1 says the tutors collect the form.
  - The example adds "No baseline supplied" on Link 2 and ends decision 5 with "before fieldwork begins on 1 Feb 2027"; the run did neither.
  - Question wording differs. Q1 in this run also gives 7 of 62; the example says only 5 not assessed.
- Facts in either output that the inputs do not give: the example says tutors collect the new form (P1) and suggests "results for similar children outside the program if the schools hold them", which assumes what the schools hold. In this run, the evidence suggestions are generic ("parent answers", "anything gathered since June") and assume no data beyond the inputs, but "tutors' record of who was absent" assumes tutors keep one.
- Ambiguities met, where the run had to choose:
  1. Whether A4 should be linked to O3 at all. A4 is children taking books home and O3 is families reading at home; the rule says same group or same place and same area of change. The run read "home" as the shared place. A4 could equally be proposed to O1, and the rule's "at most two" does not say whether to propose a second.
  2. Whether a proposed measure that names an activity applies only to that activity's links or also to all links of its outcome (step 6).
  3. Whether a timing question applies to O4, which has a later timeframe but no activity and so no link. The run did not ask one.
  4. Whether "Comments only" is stronger than "Counts only" when both are present on a link (Link 3). The list order implies it, but the template does not say it.
  5. The Dose column is read in but has no place in the output.
- Shortcoming: the template's acceptance tests are labelled proposed and none has been run; this trial is one run on one example, not a test of them.

Changed after the run recorded above, and not run again. The output and the observations above are as recorded and describe the template and the example as they stood at the run:

- **Proposed measures on links (ambiguity 2).** The template and the pasted instructions now say that a proposal applies to every link of its outcome, unless it names an activity, in which case it applies only to that activity's links. This is how the example already placed P2 and P3; the run above placed both on Links 3 and 4.
- **Linking from wording (ambiguity 1).** The template and the pasted instructions now say that an activity's wording is its Activity, Dose and Notes columns, and that if more than two outcomes qualify, none is proposed and the leads choose. The example's links are unchanged.
- **Timing for an outcome with no activity (ambiguity 3)** gets no question, now stated in the template and the pasted instructions.
- **Order of the evidence labels (ambiguity 4).** Both now say the labels run strongest first.
- **Dose (ambiguity 5).** The Reach line now shows the participants reached, the dose and the period, so the example's four Reach lines carry the dose; the run above did not show it.
- **An unknown stated outcome ID** is now a stop-and-ask in the inputs, the procedure, the exceptions and the pasted instructions, with a new acceptance test.
- **The example.** Link 1's second assumption is now about the path from the activity to the outcome, as step 7 asks (it was about the measure), and P1 says the form is collected by whoever the leads name, not by tutors.
- **The template** says "a further" evidence status, not "a third", in its customization list. The profile and the version notes state this trial and these edits.
- **Linking rule, tightened after review (ambiguity 1 again).** The review found that the rule as first edited did not discriminate: the recorded run's own note says A4 could equally be proposed to O1, and read consistently the earlier rule would have qualified O1, O2 and O3 for A4 by group or place alone, so none would be proposed. The template and the pasted instructions now say that the area of change is the thing the outcome says changes, that the activity's wording must name it, and that a shared group or place alone does not qualify. The example's A4 Notes were reworded from "Each child takes books home to keep" to "Books go home to keep, for families to read together" so that only O3 qualifies. The recorded run above used the earlier Notes and the earlier rule; its output and its observation of ambiguity 1 are left as recorded.
- **Pasted block.** It now carries the condition for each kind of question (so a starting-point or other-influences question cannot be asked at Link 4, and the count stays 13), the wording for a missing baseline or feedback file, the default lead names and the "no other influences listed" handling. The output format's condition-measures line now shows "no baseline supplied".
- **The example.** The data source of P2 and P3 reads "new collection (a parent form)"; Q1, Q2 and Q5 name kinds of evidence and no longer assume records the inputs do not mention; Q10 and decision 5 no longer choose or schedule evidence; A2's reason names the area of change.

Checked by hand after these edits, not by a new full run: the linking step was applied to the revised inputs, activity by activity. A1, A3: stated outcomes, so linked. A2: no outcome names volunteers or training, so none is proposed. A4: the Notes name families reading together; of O1 (fluency), O2 (confidence reading aloud), O3 (families reading together at home) and O4 (school attendance), only O3's area of change is named, so one link is proposed. That reproduces the example's four links, its totals and its 13 questions. The template has not been run again from the start on the revised example.
